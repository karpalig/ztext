# ztext

**Classic Philosophy Archive** — Архив китайской классической философии с переводами на русский язык

## О проекте

ztext — это коллекция важнейших текстов китайской классической философии с множественными переводами на русский язык, представленных в удобном формате для сравнительного анализа.

### Проект 1: Дао Дэ Цзин

**[ddj.shaolin60.com](https://ddj.shaolin60.com/?utm_source=github)** — все переводы «Дао Дэ Цзин» Лао-цзы на русский язык с оригинальными китайскими текстами.

Проект предоставляет уникальную возможность параллельного чтения и сравнения различных интерпретаций одного из главных памятников даосской философии.

## Технологии

Платформа для чтения работает на программе с открытым исходным кодом **[Side By Side](https://github.com/tasuki/side-by-side)** — инструменте для визуального сравнения различных переводов структурированных текстов.
